# ITMC311 Midterm MERN Repository

Generic MERN scaffold for the midterm project.

## Structure

- client/ - React + Vite frontend
- server/ - Node.js + Express backend
- server/config/ - database configuration
- server/controllers/ - feature controllers
- server/middleware/ - middleware
- server/models/ - Mongoose models
- server/routes/ - API routes
- server/utils/ - backend utilities

Feature-specific code will be added according to the final midterm instructions.
